## Limits and remaining acceptance work

The new manifests reuse the existing synthetic calibration/held-out vocabulary;
the earlier retrieval results were already visible. These are protocol measurements,
not a new unseen-data generalization claim. Inputs and the unchanged diagnostic
policy were recorded before these runs; calibration reports were frozen before
the protocol's held-out run. Mixed packs substitute other legal targets' clues
for every third target, selected without model scores. They have no human quality
labels. No independently authored, marginal or adversarial publication dataset
is claimed.

W4 must reproduce the protocol reference through the callable core, implement the
authoritative reducer and bounded queue/deadlines, and exercise the thin server and
browser against the frozen transport. The reference is not an upload or publication
service. Its development-only schema dependency does not change core dependencies.

W5 still requires human play and actual 1/4/8-player round-trip load with queue,
deadline and background verification pressure. Service durations are self-reported;
an absent inference-duration field is unknown, not zero inference time. The HTTP
residual includes network, serialization, parsing and client work; it is not a
measurement of network latency alone. GPU/offload and release hardware remain
unverified. Publication calibration and independent creator/hub parity must be
established before their respective later-stage acceptance.

The W3-to-W4 dependency boundary is closed for this scope. Stage 1 is open.
The commit containing this decision and its bound evidence is the W4 baseline.
W4 implementation has not been dispatched by this closure task.
